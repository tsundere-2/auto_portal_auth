# 校园网 Portal 自动连接（浏览器扩展 · 方案 C）

这是一个**不依赖 Python**的轻量方案：认证页一打开，扩展自动勾选"同意服务条款"并点击"连接/登录"。

适合以下场景：

- 电脑从睡眠唤醒后，系统自动弹出认证页 → 扩展立刻把按钮点掉
- 不想常驻运行 Python 进程
- 想在别人的电脑上也用（只需装扩展）

扩展与 Python 主程序**可以同时使用**，互不冲突；也可以只用其中一个。

## 安装（Edge / Chrome，只需一次）

1. 在项目目录执行：

   ```bat
   python auto_portal_auth.py install-extension
   ```

   它会自动打开浏览器的扩展管理页和 `extension/` 目录。

   也可以手动打开：
   - Edge：地址栏输入 `edge://extensions`
   - Chrome：地址栏输入 `chrome://extensions`

2. 打开右上角的 **开发人员模式 / Developer mode**

3. 点击 **加载解压缩的扩展 / Load unpacked**，选择本目录（包含 `manifest.json` 的这个文件夹）

4. 安装完成。之后打开认证页，图标上出现绿色 ✓ 就表示已经自动点击了。

> 若使用 Edge，建议在 `edge://extensions` 里把本扩展开启"允许 InPrivate"（可选）。

## 使用

- 点击工具栏图标可查看：当前页面是否被识别为认证页、识别到的按钮文本与得分
- **立即在本页执行一次**：调试未知认证页时很有用，可以直接看到识别结果
- **本网站总是启用**：把当前域名加入白名单（认证页使用内网域名时建议添加）

## 安全设计：为什么它不会在别的网站乱点

扩展注入所有 http/https 页面，因此有三道闸门：

1. **页面判定**：主机名是内网 IP（`10.x` / `172.16-31.x` / `192.168.x`），
   或 URL / 标题 / 正文包含 `portal`、`认证`、`上网`、`srun`、`eportal`、`drcom`、`wlan` 等关键词，
   或用户在弹窗中把该站点加入白名单；
2. **按钮打分**：文本、属性、元素类型综合打分，必须 ≥ 5 分才会点击；
   "取消 / 退出 / 断开 / 下载 / 注册 / 忘记密码 / 已连接"等会被扣成负分；
3. **只点一次**：点击过的元素打上标记，避免重复点击把认证搞乱。

## 与 Python 主程序的关系

| 方案 | 依赖 | 优点 | 缺点 |
|------|------|------|------|
| A. Selenium（`portal_autoclick.py`） | selenium + 浏览器驱动 | 无需人工装扩展，可无头运行，可验证联网 | 首次需要联网下载驱动；会启动浏览器进程 |
| B. HTTP 模拟（`auth.auto_login`） | 无 | 最快、最省资源 | 只适用于标准表单 Portal |
| C. 浏览器扩展（本目录） | 无 | 最轻量，页面一开就点 | 需手工安装一次；必须有浏览器窗口 |

推荐组合：**主程序负责"检测 + 自动打开认证页"，扩展负责"点掉按钮"**，
这样即使 Selenium 因驱动问题不可用，认证也能自动完成。

## 文件说明

| 文件 | 作用 |
|------|------|
| `manifest.json` | MV3 清单，声明权限与注入规则 |
| `content.js` | 注入认证页：判定页面、勾选条款、打分找按钮、点击、监听动态渲染 |
| `background.js` | Service Worker：工具栏角标、记录最近一次动作 |
| `popup.html` / `popup.js` | 弹窗：开关、延迟、手动执行、站点白名单 |

## 常见问题

**Q：安装后没有反应？**
A：认证页需要**刷新一次**（扩展安装前已打开的页面不会自动注入）。
另外确认弹窗里"启用自动点击"是打开的。

**Q：识别到了但点不动？**
A：用"立即在本页执行一次"看提示。若提示"没有找到可信的按钮"，
说明按钮文本不在词库里，请在 `content.js` 顶部的 `BUTTON_TEXTS` 里加上它的文本
（例如 `'我要上网': 9`），然后到 `edge://extensions` 点击刷新图标。

**Q：会不会把我的账号密码发出去？**
A：不会。扩展不读取、不发送任何账号密码，只做"勾选 + 点击"两件事，
数据仅保存在浏览器本地（`chrome.storage`）。
